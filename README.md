# Student Management System

A simple Student Management System built using Laravel and MySQL.

## Features

- Add new students
- Store student details in the database
- Validate student information
- CRUD operations (Create, Read, Update, Delete)

## Technologies Used

- PHP
- Laravel
- MySQL
- HTML
- Blade Templates
- Bootstrap (if used)

## Project Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/anurag842367/student-management-system.git
   ```

2. Open the project folder:

   ```bash
   cd student-management-system
   ```

3. Install dependencies:

   ```bash
   composer install
   ```

4. Create your environment file:

   ```bash
   copy .env.example .env
   ```

5. Generate the application key:

   ```bash
   php artisan key:generate
   ```

6. Configure your MySQL database in the `.env` file.

7. Run migrations:

   ```bash
   php artisan migrate
   ```

8. Start the development server:

   ```bash
   php artisan serve
   ```
